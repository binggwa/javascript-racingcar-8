# javascript-racingcar-precourse
## 구현할 기능 목록
### 입력 처리
- '경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)' 메시지를 띄우고 입력을 받아온 뒤 배열로 반환
- '시도할 횟수는 몇 회인가요?' 메시지를 띄우고 입력을 받아온 뒤 1 이상의 자연수만 반환
- 자동차 이름 에러 검출 상황
    - 쉼표기준 구분
    - 이름이 5자 이하인지 확인
    - 빈 이름이 없는지
    - 이름 사이에 공백이 없는지
    - 자동차 이름이 중복이 아닌지
- 시도할 횟수 에러 검출 상황
    - 숫자가 비어있는 경우
    - 숫자가 아닌 경우
    - 자연수가 아닌 경우
### 출력 처리
- 시도할 횟수 n만큼 반복 필요
- '실행 결과\n' 메시지를 띄우고 n차별 실행 결과 출력 필요, 차수 출력 이후에 블랭크 필요
- '최종 우승자 : ' 메시지를 띄우고 우승자 배열을 가져와 출력 필요
### 자동차
- 자동차 객체 생성자 필요
    - 이름, 현재 위치 및 게터 필요
- 1칸씩 이동하는 이동 기능 필요
    - 이동 시, 난수 체크 필요
### 자동차 경주
- 입력받은 이름을 가지고 자동차 객체 배열 생성
- 시도할 횟수만큼 반복하면서 레이스 진행 필요
    - 레이스 1사이클당 모든 자동차에 대해 이동시도
    - 매 사이클마다 각 자동차의 이름과 이동시도 이후의 위치 표시(현재 위치만큼 '-' 출력 반복)
    - n사이클 반복 후 현재 위치 수치가 가장 높은 자동차 객체 확인
    - 수치가 가장 높은 자동차를 모아 우승자 배열 생성
